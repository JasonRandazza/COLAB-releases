# COLAB — test builds

COLAB is a collaboration app for new creative professionals in streaming,
production and design. You see people one profile at a time; when two people
both say yes, they match, and only then can they talk. There is no money in
the system and never will be.

This repository holds **test builds only**. The app's source code is not public.

## Install the latest test build

1. On your Android phone, open the **[latest release](https://github.com/JasonRandazza/COLAB-releases/releases/latest)**.
2. Under **Assets**, tap the `.apk` file to download it.
3. Open the download. When Android asks, allow your browser to install apps
   from unknown sources, then tap **Install**.

Android 7.0 or newer, on a 64-bit or 32-bit ARM phone (nearly every Android
phone). There is no iOS version.

**Accounts are real.** Test builds talk to the live COLAB backend, so the
account you create is a real one, and the email address you sign up with
receives real verification codes.

**Updating:** install a newer build over the top. Your account carries over.
